# Java DSA Journey

My journey from zero programming experience to strong problem-solving and software engineering fundamentals.

## Goals

- Learn Java from the fundamentals
- Master Data Structures and Algorithms
- Solve 500+ DSA problems
- Develop strong problem-solving and pattern-recognition skills
- Understand time and space complexity
- Prepare for high-level technical interviews
- Build strong software engineering fundamentals

## Learning Approach

For every lecture:

1. Watch and understand the concept
2. Write the code myself
3. Practice the problems
4. Understand mistakes and edge cases
5. Document my learning
6. Review
7. Commit the work to Git
8. Push the work to GitHub
